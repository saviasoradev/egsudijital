# EGSU web sitesi

egsudijital.com adresinde yayınlanan EGSU web tasarım sitesinin kaynak dosyaları.

- `index.html`: sitenin tamamı (tasarım, animasyonlar, SEO etiketleri)
- `logo.png`, `logo.webp`: logo
- `favicon*.png`, `favicon.ico`, `apple-touch-icon.png`: site ikonları
- `og-image.jpg`: link paylaşıldığında görünen önizleme görseli
- `robots.txt`, `sitemap.xml`, `llms.txt`: arama motorları ve yapay zekâ botları için
- `CNAME`: GitHub Pages alan adı (egsudijital.com)
- `.nojekyll`: GitHub Pages'in dosyaları olduğu gibi yayınlamasını sağlar
