# EGSU web sitesi

egsudijital.com adresinde yayınlanan EGSU web tasarım sitesinin kaynak dosyaları.

- `index.html`: sayfanın kendisi (metinler, düzen, SEO ve yapısal veri)
- `assets/`: tasarım sistemi, hareket katmanı, hareket anları (pinned-chapters, word-highlight) ve araç ikonları
- `img/`: logo ve sayfadaki görseller
- `share.jpg`: link paylaşıldığında görünen önizleme
- `robots.txt`, `sitemap.xml`, `llms.txt`: arama motorları ve yapay zekâ botları için
- `CNAME`: GitHub Pages alan adı (egsudijital.com)
