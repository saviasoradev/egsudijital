Yönetim paneli

Sitedeki tüm yazıları, fiyatları ve referansları buradan düzenleyip yayınlayabilirsiniz.

Erişim anahtarını nasıl alırım?
  1. GitHub'da yeni anahtar sayfasını açın (saviasoradev hesabıyla).
  2. Token name alanına “EGSU panel” yazın, Expiration için 1 yıl seçin.
  3. Repository access bölümünde Only select repositories seçip egsudijital deposunu ekleyin.
  4. Permissions → Repository permissions → Contents iznini Read and write yapın.
  5. Generate token deyin, çıkan anahtarı kopyalayıp buraya yapıştırın.

Anahtar sadece bu tarayıcıda saklanır, kimseyle paylaşmayın.
